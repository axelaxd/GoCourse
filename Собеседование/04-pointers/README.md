## Ответы на вопросы

### Что делают `&` и `*`?

`&x` берёт адрес переменной и возвращает указатель. `*p` разыменовывает
указатель и даёт доступ к значению по адресу; через `*p = ...` это
значение можно изменить.

### Чем передача значения отличается от передачи указателя?

В Go аргументы всегда передаются **по значению**. Если передать
структуру, копируется структура; если передать указатель, копируется сам
адрес, поэтому функция может через него изменить исходный объект.

### Что делает `new(T)`?

`new(T)` выделяет место под zero value типа `T` и возвращает `*T`.
Например, `p := new(int)` даёт указатель на `int` со значением 0. Для
struct часто удобнее `&T{...}`.

### Почему методы структуры могут выглядеть так, будто Go автоматически разыменовывает указатель?

Для адресуемого значения компилятор разрешает удобный синтаксис вызова
методов: если метод имеет receiver `*T`, выражение `v.Method()` может
быть преобразовано примерно в `(&v).Method()`. Аналогично при доступе к
полям через указатель не приходится писать `(*p).Field`.

8.  **Указатели** - **&** и **\*** **Указатель** - переменная, которая
    хранит адрес в памяти другой переменной

    **Ссылка** - это псевдоним/алиас существующего объекта, который
    нельзя инициализировать, как `null`/`nil`, в отличие от указателя. И
    вот ссылок в Go **не существует**

    **&** - оператор взятия адреса (когда мы хотим работать именно с
    адресом в памяти, по которому лежит какое-то значение);

    **\*** - оператор разыменования (когда мы хотим получить значение,
    хранящееся по адресу).

```{=html}
<!-- -->
```
    x := 42
    p := &x // p - указатель на переменную x, хранит адрес x

    fmt.Println("Значение x:", x) // 42
    fmt.Println("Адрес x:", &x) // 0xc000012078
    fmt.Println("Значение p:", p) // 0xc000012078
    fmt.Println("Значение *p:", *p) // 42

    *p = 100 // Изменяем значение через указатель
    fmt.Println("Новое значение x:", x) // 100

    var pi *int // Указатель на int
    var ps *string // Указатель на string
    var pb *bool // Указатель на bool

    fmt.Println(pi == nil) // True

> \[!NOTE\] Нулевое значение, значение по умолчанию у указателя - это
> `nil`

9.  **Как еще создать указатель** - **new** В Golang присутствует
    специальная функция `new`, которая выделяет память для значения типа
    `T`, инициализирует его нулевым значением и возвращает указатель
    `*T`

```{=html}
<!-- -->
```
    p := new(int)
    fmt.Println(*p) // 0

    *p = 42
    fmt.Println(*p) // 42

10. **Неявные указатели** В Go некоторые типы данных содержат указатели
    внутри себя, даже если это не очевидно из синтаксиса. Эти типы часто
    называют ссылочными типами (reference types).

    В GoLang есть несколько ссылочных типов, например, **слайс и мапа**.
    Внутри себя они **содержат указатель**. Массив при это не ссылочный
    тип данных!

        fmt.Println(sl) // 1 - изменения видны

        addToMassive(ms)
        fmt.Println(ms) // [1 2] - изменения не видны
