## Ответы на вопросы

### Чем `len(string)` отличается от количества символов?

`len(s)` возвращает количество **байтов**, а не Unicode-символов. Для
ASCII это часто совпадает, но, например, кириллица в UTF-8 обычно
занимает больше одного байта на символ. Если нужно количество
Unicode-кодовых точек, можно использовать `utf8.RuneCountInString(s)`
или `len([]rune(s))`.

### Что возвращает `range` по строке?

При `for i, r := range s` переменная `i` --- **байтовый индекс начала
текущей rune**, а `r` --- Unicode-кодовая точка типа `rune`. Поэтому
индексы при UTF-8 могут идти не подряд: `0, 2, 4...`.

### Почему строки в Go immutable?

После создания содержимое строки нельзя изменить по индексу. Это делает
строки безопасными для совместного использования и позволяет Go
представлять их как неизменяемую последовательность байтов. Для
изменения обычно преобразуют строку в `[]byte` или `[]rune`, меняют
данные и создают новую строку.

### Когда нужен `[]byte`, а когда `[]rune`?

`[]byte` нужен, когда работа идёт именно с **байтами**: сеть, файлы,
протоколы, кодировки, бинарные данные. `[]rune` удобен, когда нужно
работать с Unicode-символами: например, заменить или индексировать буквы
в UTF-8 строке. `[]rune` обычно требует больше памяти.

5.  **Узнать кол-во байтов в строке** - `len()`

```go
    package main

    import "fmt"

    func main() {
        fmt.Println(len("hello"))
        fmt.Println(len("привет"))
    }
```

> [!NOTE] В ответе мы получим 5 и 12 байт в ответе. Потому что каждый
> символ кириллицы кодируется двумя байтами и len() нам об этом говорит.

6.  Посчитать кол-во букв и вывести их:

```go
package main
import "fmt"

func main() {

    var a = "hello"
    var count = 0

    for _, ch := range a {
        fmt.Println(string(ch))
        count += 1
    }

fmt.Printf("Кол-во букв: %v\n", count)
}
```

❗ Строки в Go неизменяемы! Мы не можем через обращение по индексу
изменить символ строки. При конкатенации (объединении строк) мы не
прибавляем к одной строке вторую - создается новая строка

``` go
s1 := "Строка "
s2 := "и еще строка"
s1 = s1 + s2
fmt.Println(s1)

# Строка и еще строка
```

> [!NOTE] В этом примере мы получим ожидаемый ответ, но для нового
> значения выделится новая область памяти, с которой будет работать
> переменная s1
