8. **Указатели** - **&** и **\***
	**Указатель** - переменная, которая хранит адрес в памяти другой переменной

	**Ссылка** - это псевдоним/алиас существующего объекта, который нельзя инициализировать, как `null`/`nil`, в отличие от указателя. И вот ссылок в Go **не существует**

	**&** - оператор взятия адреса (когда мы хотим работать именно с адресом в памяти, по которому лежит какое-то значение);

	**\*** - оператор разыменования (когда мы хотим получить значение, хранящееся по адресу).

```
x := 42
p := &x // p - указатель на переменную x, хранит адрес x

fmt.Println("Значение x:", x) // 42
fmt.Println("Адрес x:", &x) // 0xc000012078
fmt.Println("Значение p:", p) // 0xc000012078
fmt.Println("Значение *p:", *p) // 42

*p = 100 // Изменяем значение через указатель
fmt.Println("Новое значение x:", x) // 100

var pi *int // Указатель на int
var ps *string // Указатель на string
var pb *bool // Указатель на bool

fmt.Println(pi == nil) // True
```

> [!NOTE]
> Нулевое значение, значение по умолчанию у указателя - это `nil`

9. **Как еще создать указатель** - **new**
	В Golang присутствует специальная функция `new`, которая выделяет память для значения типа `T`, инициализирует его нулевым значением и возвращает указатель `*T`

```
p := new(int)
fmt.Println(*p) // 0

*p = 42
fmt.Println(*p) // 42
```

10. **Неявные указатели**
	В Go некоторые типы данных содержат указатели внутри себя, даже если это не очевидно из синтаксиса. Эти типы часто называют ссылочными типами (reference types).

	В GoLang есть несколько ссылочных типов, например, **слайс и мапа**. Внутри себя они **содержат указатель**. Массив при это не ссылочный тип данных!

```
func main() {
	m := map[int]int{3: 4}
	sl := make([]int, 1, 2)
	ms := [2]int{1, 2}
  
	addToMap(m)
	fmt.Println(m) // map[1:2 3:4] - изменения видные

	addToSlice(sl)
	fmt.Println(sl) // 1 - изменения видны

	addToMassive(ms)
	fmt.Println(ms) // [1 2] - изменения не видны
}

func addToMap(m map[int]int) {
	m[1] = 2
}

func addToSlice(m []int) {
	m[0] = 1
}

func addToMassive(m [2]int) {
	m[1] = 3
}
```

> [!NOTE]
> Поэтому соблюдаем предельную осторожность, когда передаем в функцию слайс или мапу. Правилом хорошего тона считается возвращать явно из функции слайс или мапу, если переменная этого типа изменяется

```
func main() {
	sl := make([]int, 1, 2)

	addToSlice(sl)
	fmt.Println(sl) // [1] - изменения не видны вне функции,
	// append перезаписал переменную
}

func addToSlice(m []int) {
	m[0] = 1
	m = append(m, 2)
	fmt.Println(m) // [1 2] - все правильно, слайс расширен
}
```

> [!NOTE]
> Все потому, что **append** перезаписывает переменную, область видимости которой из-за её передачи по значению теперь ограничивается телом функции. В таком случае необходимо явно вернуть слайс через `return`
