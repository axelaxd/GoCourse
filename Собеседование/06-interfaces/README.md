## Ответы на вопросы

### Как тип реализует интерфейс в Go?

Неявно. Никакого `implements` нет: если method set типа содержит все
методы интерфейса с нужными сигнатурами, тип удовлетворяет интерфейсу.

### Что такое пустой интерфейс / `any`?

`any` --- alias для `interface{}`. Пустой интерфейс не требует методов,
поэтому ему удовлетворяет любое значение. Использовать его стоит только
там, где тип действительно заранее неизвестен.

### Что такое type assertion и type switch?

Assertion извлекает конкретный тип: `v, ok := x.(T)`. Type switch
позволяет обработать несколько возможных динамических типов:
`switch v := x.(type) { ... }`.

### Что такое method set?

Method set --- набор методов, который участвует в проверке реализации
интерфейсов. У `T` в method set входят методы с receiver `T`; у `*T` ---
методы с receiver `T` и `*T`.

### Чем реализация интерфейса для `T` отличается от `*T`?

Если нужный метод объявлен с receiver `T`, интерфейсу обычно
удовлетворяют и `T`, и `*T`. Если обязательный метод имеет receiver
`*T`, то интерфейсу удовлетворяет `*T`, но не `T`.

### Почему интерфейс часто объявляют в месте использования?

Потребитель лучше знает минимальное поведение, которое ему нужно.
Маленький интерфейс на стороне потребителя уменьшает связанность и
позволяет поставщику не зависеть от интерфейса конкретного клиента.
