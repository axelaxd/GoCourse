# Неделя 1. Введение в Go. Простые типы данных и управляющие конструкции

1. Первая программа Hello World
```go
package main

import "fmt"

/*

	Многострочный
	комментарий

*/

func main() {
	fmt.Println("Hello, world!")
}
```

2. **Сборка в исполняемый файл** - `go build`

	`go build <file>.go` - создает исполняемый файл .exe, предназначенный для той OC и архитектуры, в которой выполняется сама команда

	Но в GO также можно создать исполняемый файл и для другой OC, добавив 
		**GOOS** - целевую OC, под которую планируется создать (windows, mac)
		**GOARCH** - ожидаемую архитектуру этой системы (amd64)

	`GOAS=windows GOARCH=amd64 go build hello_world.go`

3. **Запуск программы через консоль** - `go run`

	`go run <file>.go`

4. **Базовые типы данных в Go**
	**Целые числа**

| Тип    | Описание                                  | Примеры значений           |
| ------ | ----------------------------------------- | -------------------------- |
| int    | Целое число                               | `42, -10`                  |
| int32  | Целое число от -2 млрд до 2 млрд          | `-100000`, `2147483647`    |
| int64  | Целое число от -9 квадр до 9 квадр        | `-500000000`, `9223372036` |
| uint   | Беззнаковое целое число                   | `0`, `100256`              |
| uint32 | Беззнаковое целое число от 0 до 4 млрд.   | `0`, `42`                  |
| uint64 | Беззнаковое целое число от 0 до 18 квадр. | `0`, `101`                 |

	Числа с плавающей точкой

| Тип     | Описание                           | Пример значений            |
| ------- | ---------------------------------- | -------------------------- |
| float32 | Число с плавающей точкой (32 бита) | `3.14`, `-0.0001`          |
| float64 | Число с плавающей точкой (64 бита) | `3.141592653589793`, `0.1` |
	**Логический тип**
	bool - логический тип в Golang. Занимает 1 байт, имеющий значение true или false. 

	Попытки использовать 1 и 0 приведут к ошибкам компиляции
\
	**Строки**

| Тип    | Описание      | Примеры значений   |
| ------ | ------------- | ------------------ |
| string | Строка текста | `"Hello, Go!", ""` |
	Ожидается, что строка содержит UTF-8 байты, представляющие Unicode-кодовые точки. Ввиду природы строк, по ним можно пройтись циклом:

```go
for i, ch := range "hello" {
	fmt.Println("Номер: ", i, ", символ: ", ch)
}

#Номер:  0 , символ:  104
#Номер:  1 , символ:  101
#Номер:  2 , символ:  108
#Номер:  3 , символ:  108
#Номер:  4 , символ:  111
```

5. **Узнать кол-во байтов в строке** - `len()`
```
package main

import "fmt"

func main() {
	fmt.Println(len("hello"))
	fmt.Println(len("привет"))
}
```

> [!NOTE]
> В ответе мы получим 5 и 12 байт в ответе. Потому что каждый символ кириллицы кодируется двумя байтами и len() нам об этом говорит.

6. Посчитать кол-во букв и вывести их:
```go
package main
import "fmt"

func main() {

	var a = "hello"
	var count = 0

	for _, ch := range a {
		fmt.Println(string(ch))
		count += 1
	}

fmt.Printf("Кол-во букв: %v\n", count)

}
```

❗ Строки в Go неизменяемы! Мы не можем через обращение по индексу изменить символ строки. При конкатенации (объединении строк) мы не прибавляем к одной строке вторую - создается новая строка

```go
s1 := "Строка "
s2 := "и еще строка"
s1 = s1 + s2
fmt.Println(s1)

# Строка и еще строка
```

> [!NOTE]
> В этом примере мы получим ожидаемый ответ, но для нового значения выделится новая область памяти, с которой будет работать переменная s1

7. **Более хитрые типы**

| Тип  | Описание                                     |  Примеры значений   |
| ---- | -------------------------------------------- | :-----------------: |
| byte | Синоним типа `uint8`, представляет байты     |      `'a', 97`      |
| rune | Синоним типа `int32`, представляет в Unicode | `'ы'`, `0x0000044B` |

	Когда мы проходимся циклом по строке, то получаем как раз руны, с
	которыми уже можно взаимодействовать как с отдельными символами

> [!NOTE]
> Для вывода символа нужно использовать форматирование 
> `%c` выводит символ (для `rune` и `byte`)
> `%q` выводит экранированный символ (в кавычках)
> `%U` для вывода руна -> Unicode code


8. **Способы определения переменных** - `var`
```go
var i int = 1
var w float64 = 12.5

var i = 1                     // int
var w = 12.5             // float64
var name = "John" // string

Если значение отсутствует, то переменная объявляется с **"нулевым"** для данного типа значением: 0 для чисел, false для булевого типа, пустая строка для строк:
	
var i int                         // 0
var w float64              // 0.0
var isPresent bool     // false
var name string         // ""

Можно определять несколько переменных** сразу единым блоком:
	
var i, j, k int = 1, 2, 3
var (
	name           string = "John Doe"
	occupation string = "gardener"
)
```

И наконец, короткое определение переменной с помощью `:=`

```go
name := "John Doe"
age := 34
```

9. **Константы** - `const`
	Неизменяемые переменные, которые определяются на стадии компиляции. Они объявляются с помощью ключевого слова const:

```go
const Pi = 3.14159

const name string = "My name"
const surname = "My surname"

const (
	StatusOK = 200
	StatusNotFound = 404
)
```

10. **if/else**
- Условие `if` должно быть выражением типа `bool`;
- Условие не требуется оборачивать круглыми скобками;
- переменные, объявленные внутри тела блока, видны только внутри блока;

```go
x := 10

if x > 5 {
	fmt.Println("x больше 5") // выведется в консоль
}

```

**else if**

```go
if x > 0 {
	fmt.Println("Положительное")
} else if x < 0 {
	fmt.Println("Отрицательное")
} else {
	fmt.Println("Ноль")
}
```

11. **Удобная версия if/else** - `switch`
- `switch` **содержит** в себе некоторое значение, с которым мы будем работать во всех условиях выбора;
- `case` - это наши **варианты выбора**. Если бы мы нашли `case` с подходящим значением, то выполнили бы код этого кейса и **сразу** вышли бы из конструкции
- `default` позволяет нам перехватывать все остальные случаи, которые мы не рассмотрели

```go
switch time.Now().Weekday() {
case time.Saturday:
	fmt.Println("Today is Saturday")
case time.Sunday:
	fmt.Println("Today is Sunday")
default:
	fmt.Println("Today is a working day")
}

```

- Но можно не использовать никакого значения у самого `switch`. Он сам по себе может быть пустым

```go
hour := time.Now().Hour()

switch {
case hour < 12:
	fmt.Println("Good morning!")
case hour < 17:
	fmt.Println("Good afternoon!")
default:
	fmt.Println("Good evening!")
}
```

- Выполнением `switch` можно управлять двумя операторами: `break` и `fallthrough`
	`break` - выходит из  конструкции
	`fallthrough` - выполняет следующую ветку `case` без повторной проверки ее условия

12. **Множественные выражения** - `&&` / `||` / `!`
**Оператор И (&&)**
```go
isUser := true
isAdmin := true

if isUser && isAdmin {
	fmt.Println("Operation completed") // Произойдет печать в консоль
}
```

**Оператор ИЛИ (||)**
```go
isClosed := true
isWeekend := false

if isClosed || isWeekend {
	fmt.Println("You can't order now") // Тоже увидим текст в консоли
}
```

**Оператор НЕ (!)**
```go
isClosed := true
isWeeknd := true

if !(isClosed || isWeekend) {
	fmt.Println("You can order now") // Ничего не выведем
}
```

13. **Циклы** -  `for`
	Оператор `while` в Go идеологически отсутствует

**Цикл в виде C**

```go
sum := 0


for i := 1; i < 5; i++ {
	sum += i
}

fmt.Println(sum)
```

**Аналог цикла while**

```go
n := 1

for n < 5 {
	n *= 2
}

fmt.Println(n) // 8
```


**Бесконечный цикл**

```go
sum := 0

for {
	sum++
	fmt.Println(sum)
}
```

Для того чтобы **взаимодействовать с различными стуктурами** данных, используется конструкция `for-range`

```go
for индекс, значение := range структура данных {
// Тело цикла
}
```

**Пример** `for-range`

```go
for i, ch := range "hello" {
	fmt.Println("Индекс: ", i, ", значение: ", ch) // RUNE!!!!
}
```

```go
for i := range 5 {
	fmt.Println(i) // 0, 1, 2, 3, 4
}
```

14. **Цикл в цикле**
	В случае когда требуется прервать выполнение всех родительских циклов из вложенного, используется так называемые `метки` - строковый лейбл

```go
sum := 0

outer:
for {
	sum++
	for j := 0; j < sum; j++ {
		if j*sum == 111 {
			break outer // Тут мы выйдем из всех циклов разом.
		}
	}
}
```

15. **Continue** 
	Используется, когда **работа в рамках текущей итерации уже завершена** и нужно досрочно перейти на следующую итерацию.

```go
sum := 0

for i := 1; i < 5; i++ {
	if i % 2 != 0 {
		continue
	}

	sum += i

}

fmt.Println(sum) // 6 (2+4)
```

16. **Итерация по индексам**
	Если требуется итерироваться только по индексам, второе значение можно опустить

```go
strings := [3]string{"I", "love", "Go"}
for i := range strings {
	fmt.Println(strings[i])
}
```

17. Итерация только по значению - `_`
	Опускаем значение (индекс) с помощью символа подчёркивания

```go
strings := [3]string{"I", "love", "Go"}
for _, s := range strings {
	fmt.Println(s)
}
```
