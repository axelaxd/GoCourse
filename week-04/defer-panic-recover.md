# Быстро повторить: `defer`, `panic`, `recover`

[← К полной неделе](./README.md) · [↑ К содержанию курса](../README.md)

## `defer`

`defer` откладывает вызов функции до момента завершения текущей функции.

Один из типичных случаев из курса — освобождение ресурсов:

```go
file, err := os.Open("file.txt")
if err != nil {
    return err
}
defer file.Close()
```

Идея: ресурс успешно получили — сразу запланировали его освобождение.

## `panic`

`panic()` в конспекте рассматривается не как обычная ошибка, а как фатальная ситуация:

```go
panic("Panic!")
```

При необработанной панике выполнение программы прекращается и выводится стек вызовов.

Обычные ожидаемые ошибки приложения должны обрабатываться через `error`, а не превращаться в `panic`.

## `recover`

`recover` позволяет перехватить панику.

Ключевое правило из конспекта: `recover` используется вместе с `defer`.

```go
func Example() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("Recovered:", r)
        }
    }()

    panic("Panic!")
}
```

После перехвата паники вызывающий код может продолжить выполнение.

## Связка

```text
обычная ошибка → error
фатальная ситуация → panic
перехват panic → defer + recover
```
