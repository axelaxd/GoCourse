# Неделя 2. Составные типы данных. Знакомство с исходным кодом Go

1. **Массивы**
	`Размер массива задается во время его объявления`, является частью типа.
	
	Массив является сравниваемым типом (с ним можно проводить операции сравнения ` и !=), сравнить массивы с разной длиной нельзя

```go
var numbers3 [3]int // Массив из трёх целых чисел
var numbers5 [5]int // Массив из пяти целых чисел

numbers3 ` number5 // Ошбика компиляции: разные типы
```

В случае использования ключевого слова var созданный массив будет 
содержать столько zero value, сколько было указано в квадратных
скобках

```go
var temperatures [7]float64  // Семь температур на неделю
var scores [5]string         // Пять оценок студента

fmt.Println(temperatures)   // [0 0 0 0 0 0 0] — нулевые значения 
fmt.Println(scores)         // ["" "" "" "" ""] — нулевые значения 
```

> [!NOTE]
> Но есть и другие способы. Можем инициализировать все значения массива сразу, либо заполнять его частично, либо создавать разреженные массивы

```go
// Все значения сразу
weekdays := [7]string{
	"Понедельник", "Вторник", "Среда", "Четверг",
	"Пятница", "Суббота", "Воскресенье",
}

// Частичная инициализация значений
grades := [5]int{95, 87, 92} // [95 87 92 0 0] - остальные нули

```

2. **Длина и ёмкость массива** - `len` и `cap`
	`len` - функция, которая возвращает длину значения, то есть количество элементов в типе, которые он в себе непосредственно содержит;

	`cap` - функция, которая возвращает ёмкость значения, то есть максимальное количество элементов, которое тип может содержать

> [!NOTE]
> В случае с массивом мы имеем соответствие len(x) ` cap(x)

```go
fruits := [4]string{
	"яблоко", "банан",
	"апельсин", "груша",
}

// С индексом и значением
for index, fruit := range fruits {
	fmt.Printf("%d. %s\n", index+1, fruit)
}

// Только значения
for _, fruit := range fruits {
	fmt.Println("Фрукт: ", fruit)
}
  
// Только индексы
for index := range fruits {
	fmt.Printf("Индекс %d\n", index)
}
```

#### Ограничения массивов
- **Фиксированный размер**: после объявления массива изменить его размер нельзя;
- **Размер - часть типа**: \[10]int и \[20]int несовместимы;
- **Копирование при передаче**: дорого для больших массивов.

3. **Гибка альтернатива массивам** - `слайсы`
	**Отличие**: слайсы имеют динамический размер;
	
	Слайс не имеет длины как часть типа, и объявляется без числа в квадратных скобках

```go
var numbers []int // Пустой слайс целых чисел
var names []string // Пустой слайс строк
```

- Истинно пустой массив можно создать иначе:
`empty := []int{}`

##### Новый вариант создания
- Через новую функцию make, являющуюся идиоматичным способом объявления слайсов.

	Принимает на вход тип слайса, который надо создать, кол-во элементов этого слайса и общую ёмкость

```go
// make([]T, length)
numbers := make([]int, 5) // [0 0 0 0 0], len=5, cap=5

// make([]T, length, capacity)
buffer := make([]int, 0, 10) // [], len=0, cap=10
```

> [!NOTE]
> В отличии от массива, len вернет нам кол-во элементов в слайсе (заполненных индексов)

4. **Функция для увеличения слайла** - `append`

```go
var shopping []string

shopping = append(shopping, "хлеб")
shopping = append(shopping, "молоко", "яйца")

fmt.Println(shopping)
fmt.Println(len(shopping))

# [хлеб молоко яйца]
# 3
```

❗append возвращает новый слайс! Поэтому результат его вычисления нужно присваивать обратно переменой, которую мы расширяем. Но что происходит под капотом?

1. Если в слайсе есть свободное место (`len < cap`), слайс не расширяется и `append` дописывает элемент в слайс, увеличивая длину.
2. Если места нет (len \=\= cap), создаётся новый слайс, туда копируются старые элементы и добавляется новый

**Отличие слайсов от массивов №3**: слайсы несравниваемый тип, в отличие от массивов

Отличие слайсов от массивов №4: массив остается массивом, слайс/срез можно брать от массива и от слайса

```go
months := [12+1]string{
	"", "January", "February", "March", "April", "May", "June",
	"July", "August", "September", "October", "November", "December",
}

var (
	allMonths = months[:]
	firstHalf = months[1 : 6+1]
	secondHalf = months[7:]
	summer = months[6: 8+1]
)

fmt.Println(allMonths)
fmt.Println("Лето:", summer)
fmt.Println("Первая половина:", firstHalf)
fmt.Println("Вторая половина:", secondHalf)
```

Синтаксис среза `\[start:end]` означает "взять элементы с индекса" `start` до индекса `end`, не включая `end`. Если старт опущен - берем с начала, если `end` опущен - до конца. Все эти слайсы ссылаются на **один и тот же** базовый массив

```go
summer[0] = "ИЮНЬ"                         // Изменяем слайс
fmt.Println("Исходный массив:", months[6]) // ИЮНЬ - массив изменился!
fmt.Println("Первая половина:", firstHalf[6-1]) // ИЮНЬ - изменилось!
```

> [!NOTE]
> Это показывает, что если изменить элемент через один слайс, то это сразу повлияет на базовый массив и станет видно по всех остальных слайсах!

5. **Скопировать слайс** - `copy`

```go
original := []string{"a", "b", "c", "d", "e"}

// ОБЯЗАТЕЛЬНО создаем слайс-получатель через make
destination := make([]string, len(original))

// Копируем элементы
n := copy(destination, original)
fmt.Printf("Скопировано %d элементов\n", n) // 5

// Изменяем копию — оригинал не изменится
destination[0] = "MODIFIED"

fmt.Println("Оригинал:", original)     // [a b c d e]
fmt.Println("Копия:   ", destination)  // [MODIFIED b c d e]

```

6. **Нулевое значение** - `nil` 
	nil - специальное нулевое значение для ссылочных типов. Оно означает "ничего" или "пустой указатель".

7. **Встроенные хеш-таблицы**: `map`
	Это еще один встроенный тип данных, предназначенный для хранения ассоциативных данных в виде пары `ключ - значение`

```go
var m map[int]string
```

> [!NOTE]
> В примере выше важно то, что мапа хоть и объявлена, но не инициализирована. То есть она имеет значение nil, в случае попытки записи в такую мапу получим ошибку.

##### Работа с мапами
```go
m1 := make(map[int]bool) // Пустая
m2 := make(map[bool]int, 10) // Инициалиированная
m3 := map[float32]bool{1.2: true, 1.5: false} // Со значениями
```

- Чтение и запись осуществляются тривиально - через обращение по ключу. Удаление ключа происходит через встроенную функцию `delete`

**Как проверить существования ключа?**
- Нужно проверить существование ключа через нотацию `value-ok`, где ok - это булевое значение;

```go
m := make(map[int]bool)
m[1] = true // Запись
fmt.Println(m[1]) // Чтение: true
delete(m, 1) // Удаление

v, ok := m[2] // v = это всегда значение по ключу
if !ok {
	fmt.Println("ключа нет!")
}

var m1 map[int]int

fmt.Println(len(m1), len(m)) // 0 получим
```

> [!NOTE]
> Хорошей практикой является проверять мапу не на nil, а на длину

```go
for k, v := range m { // k - ключ, v - значения. Получение рандомно
	fmt.Println(k, v)
}
fmt.Println(m) // Всегда один и тот же порядок данных
```

8. **Указатели** - `&` и `\*`
	`Указатель` - переменная, которая хранит адрес в памяти другой переменной

	`Ссылка` - это псевдоним/алиас существующего объекта, который нельзя инициализировать, как `null`/`nil`, в отличие от указателя. И вот ссылок в Go **не существует**

	`&` - оператор взятия адреса (когда мы хотим работать именно с адресом в памяти, по которому лежит какое-то значение);

	`\*` - оператор разыменования (когда мы хотим получить значение, хранящееся по адресу).

```go
x := 42
p := &x // p - указатель на переменную x, хранит адрес x

fmt.Println("Значение x:", x) // 42
fmt.Println("Адрес x:", &x) // 0xc000012078
fmt.Println("Значение p:", p) // 0xc000012078
fmt.Println("Значение *p:", *p) // 42

*p = 100 // Изменяем значение через указатель
fmt.Println("Новое значение x:", x) // 100

var pi *int // Указатель на int
var ps *string // Указатель на string
var pb *bool // Указатель на bool

fmt.Println(pi ` nil) // True
```

> [!NOTE]
> Нулевое значение, значение по умолчанию у указателя - это `nil`

9. **Как еще создать указатель** - `new`
	В Golang присутствует специальная функция `new`, которая выделяет память для значения типа `T`, инициализирует его нулевым значением и возвращает указатель `*T`

```go
p := new(int)
fmt.Println(*p) // 0

*p = 42
fmt.Println(*p) // 42
```

10. **Неявные указатели**
	В Go некоторые типы данных содержат указатели внутри себя, даже если это не очевидно из синтаксиса. Эти типы часто называют ссылочными типами (reference types).

	В GoLang есть несколько ссылочных типов, например, `слайс и мапа`. Внутри себя они **содержат указатель**. Массив при это не ссылочный тип данных!

```go
func main() {
	m := map[int]int{3: 4}
	sl := make([]int, 1, 2)
	ms := [2]int{1, 2}
  
	addToMap(m)
	fmt.Println(m) // map[1:2 3:4] - изменения видные

	addToSlice(sl)
	fmt.Println(sl) // 1 - изменения видны

	addToMassive(ms)
	fmt.Println(ms) // [1 2] - изменения не видны
}

func addToMap(m map[int]int) {
	m[1] = 2
}

func addToSlice(m []int) {
	m[0] = 1
}

func addToMassive(m [2]int) {
	m[1] = 3
}
```

> [!NOTE]
> Поэтому соблюдаем предельную осторожность, когда передаем в функцию слайс или мапу. Правилом хорошего тона считается возвращать явно из функции слайс или мапу, если переменная этого типа изменяется

```go
func main() {
	sl := make([]int, 1, 2)

	addToSlice(sl)
	fmt.Println(sl) // [1] - изменения не видны вне функции,
	// append перезаписал переменную
}

func addToSlice(m []int) {
	m[0] = 1
	m = append(m, 2)
	fmt.Println(m) // [1 2] - все правильно, слайс расширен
}
```

> [!NOTE]
> Все потому, что `append` перезаписывает переменную, область видимости которой из-за её передачи по значению теперь ограничивается телом функции. В таком случае необходимо явно вернуть слайс через `return`
