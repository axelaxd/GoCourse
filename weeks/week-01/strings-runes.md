# Быстро повторить: строки, UTF-8, `byte` и `rune`

[← К полной неделе](./README.md) · [↑ К содержанию курса](../README.md)

## Главное

Строка в Go содержит байты. В конспекте ожидается UTF-8 представление Unicode-кодовых точек.

```go
s := "привет"
fmt.Println(len(s))
```

`len()` для строки возвращает **количество байтов**, а не количество символов. Поэтому для кириллицы число байтов и число букв отличаются.

При обходе строки через `range` мы получаем индекс и Unicode-кодовую точку:

```go
for i, ch := range "hello" {
    fmt.Println(i, ch)
}
```

Если нужен сам символ:

```go
fmt.Println(string(ch))
```

## `byte` и `rune`

```go
byte // alias для uint8
rune // alias для int32
```

В конспекте `byte` используется как представление байта, а `rune` — Unicode-кодовой точки.

## Неизменяемость строк

Строки в Go **неизменяемы**. Нельзя заменить символ строки через индекс.

```go
s := "hello"
// s[0] = 'H' // так нельзя
```

При конкатенации создаётся новое строковое значение:

```go
s1 := "Строка "
s2 := "и еще строка"

s1 = s1 + s2
```
