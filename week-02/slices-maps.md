## Массив и слайс

У массива размер является частью типа:

```go
var a [3]int
var b [5]int
```

`[3]int` и `[5]int` — разные типы.

Слайс объявляется без размера:

```go
var numbers []int
```

Создание через `make`:

```go
a := make([]int, 5)     // len=5, cap=5
b := make([]int, 0, 10) // len=0, cap=10
```

## `len`, `cap` и `append`

`len` — текущая длина слайса, `cap` — его ёмкость.

```go
s = append(s, 10)
```

Важно: `append` **возвращает слайс**, поэтому результат нужно присваивать.

Если `len < cap`, новый элемент помещается в имеющуюся ёмкость.

Если `len == cap`, создаётся новый массив для хранения элементов, старые элементы копируются, после чего добавляется новый.

## `map`

`map` хранит пары ключ-значение:

```go
m := make(map[int]string)
m[1] = "one"
```

Объявленная, но не инициализированная map имеет значение `nil`:

```go
var m map[int]string
```

Читать такую map можно, но попытка записи приведёт к ошибке во время выполнения.

## Проверка существования ключа

Используется `value, ok`:

```go
value, ok := m[key]
if !ok {
    // ключа нет
}
```

Удаление:

```go
delete(m, key)
```
