# Введение в Go

## Простые типы данных и управляющие конструкции

1. Первая программа Hello World
```go
package main

import "fmt"

/*
    Многострочный
    комментарий
*/

func main() {
    fmt.Println("Hello, World!")
}
```

2. Основные команды

```
go build <file>.go - создаёт исполняемый файл .exe (для той OC, в которой выполняется программа)
```
* Также можно создать исполняемый файл и для другой OC:
    - GOOS: целевая OC (windows, mac)
    - GOARCH: ожидаемая архитектура системы (amd64)
    
    GOAS=windows GOARCH=amd64 go build hello_world.go

```
go run <file>.go - запуск программы через консоль
```

3. Базовые типы данных в Go

| Тип | Описание | Примеры значений |
| :---: | :--- | :--- |

| int64 | от -9 до 9 квадр | -500000000 |

| uint32 | от 0 до 4 млрд | 0, 42 |
| uint64 | от 0 до 18 квадр | 0, 101 |
|  |  |  |
| float32 | Дробное число (32 бита) | 3.14, -0.0001 |
| float 64 | 64 бита | 3.141592653589793 |
|  |  |  |
| bool | логический тип | true, false |
|  | | |
| string | Строка текста | "Hello, Go!", "" |
