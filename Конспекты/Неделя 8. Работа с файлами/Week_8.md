# Работа с файлами

Очевидно, что при работе с файлами мы можем использовать следующие основные операции:
- открытие файлов;
- чтение файла;
- запись в файл;
- создание файлов;
- проверка их существования

1. **Пакет для работы с файлами** - `os`

```go
type File struct {
	*file // os specific
}
```

Здесь структура `File` содержит неэкспортируемое представление системной информации о файле, позволяя тем самым оборачивать его

**Важное замечание**: как говорится в документации к `File`, все его методы являются конкурентно безопасными

2. **Открытие файла** - `os.Open()` и `os.OpenFile()`
	`os.Open()` - открываем файл **только для чтения**, и если такого файла не существует в директории, то вернётся ошибка типа `type PathError = fs.PathError`

```go
file, err := os.Open("input.txt")
if err != nil {
	return err
}

defer file.Close()
```

Однако правильнее вызывать закрытие всё же с обработкой ошибки:

```go
defer func() {
	if err := file.Close(); err != nil {
		fmt.Println(err)
	}
}
```

**os.OpenFile()**
	`os.OpenFile()` - можно открыть файл и для чтения, и для записи, и создавая его перед использованием. Для этого надо использовать **определённые флаги** вторым аргументом (также уровни доступа)

```go
file, err := os.OpenFile("notes.txt", os.O_RDWR|os.O_Create, 0644)
if err != nil {
	log.Fatal(err)
}

if err := file.Close(); err != nil {
	log.Fatal(err)
}
```

**Дальнейшее чтение** с помощью переменной `file` можно осуществлять через метод `Read`, который позволяет читать конкретное кол-во байтов в переданный в качестве аргумента слайс

```go
b := make([]byte, 1024)

for {
	n, err := file.Read(b) // Возвращает кол-во прочитанных байтов
	if err != nil {
		if errors.Is(err, io.EOF) {
			return nil
		}
		
		return fmt.Errorf("Warning: %w", err)
 	}
}
```

3. **Чтение файла, как и создание** - `os.ReadFile`
	Бывает удобно, но не с большими файлами, так как вызов блокирует выполнение до полного чтения файла.

```go
data, err := os.ReadFile("input.txt")
if err != nil {
	log.Fatal(err)
}

fmt.Print(string(data))
```

4. **Создать файл** - `os.Create()`
	io.EOF - сигнализирует о конце файла. "End of File"
	
```go
// Открытие дескриптора файла
    file, err := os.Create("large_file.txt")
    if err != nil {
        fmt.Printf("Ошибка открытия файла: %v\n", err)
        return
    }
    defer file.Close()
    var buffer = make([]byte, 4096) // Буфер размером 4 КБ
    for {
        // Чтение следующих 4 КБ файла
        n, err := file.Read(buffer)
        if err ` io.EOF {
            break
        }
        // Обработка данных из буфера
    }
```

❗ Если мы пробуем создать новый файл, но такой уже существует - старый файл просто очиститься

5. **Проверить, есть ли файл в директории** - `os.Stat` + `fs.ErrNotExist`
	Библиотека `fs` импортируется как : `io/fs`

```go
func fileExists(filename string) (bool, error) {
    _, err := os.Stat(filename)
    if err ` nil {
        return true, nil
    }
    
    if errors.Is(err, fs.ErrNotExist) {
        return false, nil
    }
    
    return false, err
}
```

6. **Писать в файл** - `os.WriteFile()`  / `file.WriteString`
	Если файл существует, функция перепишет его

```go
err := os.WriteFile("testdata/helo", []byte("Hello, Gophers!), 0666)
if err != nil {
	log.Fatal(err)
}
```

7. **Удалить файл** - `os.Remove()`

8. **Основные правила для работы с файлами и куда вставлять append, create, write**

- `os.O_APPEND|os.O_WRONLY` - всегда добавит в конец
- `os.WRONLY` - пишет с текущей позиции (обычно первая строка)
- `os.O_TRUNC` - полная перезапись

#### Пакет io

- `io.Reader` — описывает типы, читающие данные методом `Read(p []byte) (int, error)`. А мы ведь его видели в пакете `os`!

- `io.Writer` — описывает типы, записывающие данные методом `Write(p []byte) (int, error)`.

- `io.Closer` — описывает типы, освобождающие ресурсы методом `Close() error`.

- `io.ReadWriter` — объединяет интерфейсы `io.Reader` и `io.Writer`.

- `io.ReadCloser`, `WriteCloser` — объединяют интерфейсы `io.Reader/io.Writer` и `io.Closer` и так далее.

#### Работа с большими файлами

9. **Готовые решения с большими объемами данных** - `bufio`
	Здесь можно делать все: читать, писать, перезаписывать данные
	
	`bufio.Scanner` представляет из себя **высокоуровневый инструмент** для последовательного чтения данных. Чаще всего текстовых:

```go
file, err := os.Open("input.txt")
	if err != nil {
		log.Fatal(err)
	}

	defer file.Close()

	scanner := bufio.NewScanner(file) // Создаем сканнер
	for scanner.Scan() { // Здесь мы его читаем
		fmt.Println(scanner.Text()) // Текст
	}

	if err := scanner.Err(); err != nil {
		log.Fatalf("Ошибка чтения: %v", err)
	}
```

Здесь мы **получаем дескриптор файла** для чтения и передаем его в конструктор. И далее `scanner` сам возвращаем нам построчный вывод **разделяя поток данных** по нужным токенам (например, `\n`)


Однако в случаях длинных строк, бинарных данных и желания управлять чтением серьезнее, лучше посмотреть в сторону `bufio.NewReader(io.Reader)`

10. **Считывать данные из произвольного места** - `io.Seeker`
```go
file.Seek(0, io.SeekStart)
```

Подобная запись говорит нам о том, что мы хотим вычитать файл с нулевого байта, отсчитывая с начала этого файла

#### Обход файловой системы
В Go для этого используются всё те же `os` и `path/filepath` для работы с путями и обходом директорий

11. **Создание директорий** - `os.Mkdir()` или `osMkdirAll()`
	`os.Mkdir()` - создаёт директорию

	`os.MkdirAll()` - создаёт всю цепочку директорий, если её не существует:

	Не пересоздаст директорию, если такая уже есть

```go
err := os.MkdirAll("data/logs", 0755)
if err != nil {
	log.Fatal(err)
}
```

#### Чтение содержимого директорий

12. **Чтение директорий** - `os.ReadDir()`
```go
entries, err := os.ReadDir("./w08")
if err != nil {
	log.Fatal(err)
}

for _, entry := range entries {
	if entry.IsDir() {
		fmt.Println("Каталог:", entry.Name())
	} else {
		fmt.Println("Файл:", entry.Name())
	}
}
```

13. **Рекурсивный обход** - `filepath.WalkDir`
```go
filepath.WalkDir(".", func (path string, d fs.DirEntry, err error) error {
  if err != nil {
    return err
  }
  
  if !d.IsDir() {
    fmt.Println(path)
  }
  
  return nil
})
```

`WalkDir` принимает точку входа для обхода и функцию, которая называется *обработчиком обхода*. Это функция, которая **вызывается для каждого элемента файловой системы** во время рекурсивного обхода

#### Аргументы и флаги

При запуске программ часто требуется передать имя файла или указать порт прослушивания. Для этого используются аргументы командной строки

14. **Получить аргументы командной строки** - `os.Args`
	Это *глобальная переменная типа слайса строк*, которая при запуске программы считывает все аргументы командной строки запуска в функции init()

```go
package main

import (
    "fmt"
    "os"
)

func main() {
    fmt.Println("Количество аргументов:", len(os.Args)-1)
    fmt.Println("Название программы:", os.Args[0])
    
    if len(os.Args) > 1 {
        fmt.Println("Аргументы:")
        for i, arg := range os.Args[1:] {
            fmt.Printf("  %d: %s\n", i+1, arg)
        }
    }
}
```

```go
go run main.go hello world 123
```

```go
Коичество аргементов: 3
Название программы: /tmp/go-build123456/b001/main
Аргументы:
	1: hello
	2: world
	3: 123
```

**Заметим, что в примере выше** считаем кол-во аргументов как len(os.Args)-1. `os.Args[0]` всегда содержит имя программы

15. **Более сложная обработка данных** - пакет `flag`
	Пакет автоматически обрабатывает различные форматы передачи флагов

```go
package main
import (
    "flag"
    "fmt"
)

func main() {
    // Определение флагов
    var (
        name    = flag.String("name", "Мир", "имя для приветствия")
        count   = flag.Int("count", 1, "количество повторений")
        verbose = flag.Bool("verbose", false, "подробный вывод")
    )
    
    // Парсинг аргументов (должен быть вызван после объявления всех флагов)
    flag.Parse()
    
    if *verbose {
        fmt.Printf("Выполняется приветствие с параметрами: name=%s, count=%d\n", *name, *count)
    }
    
    n := *count
    for range n {
        fmt.Printf("Привет, %s!\n", *name)
    }
}
```

```go
go run main.go -name="Алиса" -count=3 -verbose
```

```
Выполняется приветствие с параметрами: name=Алиса, count=3
Привет, Алиса!
Привет, Алиса!
Привет, Алиса!
```

**Но и здесь присутствуют важные моменты, о которых надо помнить**. В пакете `flag` нет прямой функции, чтобы узнать был ли указан флаг пользователем, поэтому для флагов требуется всегда указывать значение по умолчанию.

При стиле определения флагов выше **переменные являются указателями**, поэтому их придётся дополнительно разыменовывать

**в Go -flag и --flag являются идентичными**. В силу этого в экосистеме Go принято придерживаться стиля авторов и использовать флаги с одним дефисом

А еще мы можем определять неименованные аргументы после флагов. Они используются, когда программе нужно обработать список элементов (файлов, URL, имен пользователей и так далее)

```go
package main
import (
    "flag"
    "fmt"
)
func main() {
    var prefix = flag.String("prefix", "", "префикс для файлов")
    flag.Parse()
    
    files := flag.Args() // Получаем неименованные аргументы
    
    if len(files) == 0 {
        fmt.Println("Не указаны файлы для обработки")
        return
    }
    
    fmt.Printf("Обрабатываем %d файлов:\n", len(files))
    for _, file := range files {
        fmt.Printf("- %s%s\n", *prefix, file)
    }
}
```
