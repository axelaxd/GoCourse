# Быстро повторить: интерфейсы, `any` и type assertion

## Интерфейс

Интерфейс в Go определяет набор методов — то есть требуемое поведение.

```go
type Shape interface {
    Area() float64
    Perimeter() float64
}
```

Функция может принимать интерфейс и работать с разными конкретными типами:

```go
func printShapeInfo(s Shape) {
    fmt.Println(s.Area())
    fmt.Println(s.Perimeter())
}
```

Для вызывающего кода важен контракт интерфейса, а не конкретный тип.

## Пустой интерфейс и `any`

Пустой интерфейс не требует ни одного метода:

```go
interface{}
```

Поэтому ему удовлетворяет любой тип.

`any` используется как универсальный тип там, где конкретный тип заранее не определён.

## Type assertion

Чтобы получить конкретный тип из интерфейсного значения, используется type assertion.

Безопасный вариант:

```go
value, ok := x.(string)
if !ok {
    // внутри x не string
}
```

Именно `ok` позволяет проверить приведение без аварийного завершения.
