## Горутины

Функцию можно запустить конкурентно через `go`:

```go
go worker()
```

Порядок выполнения горутин не гарантирован.

Важно помнить: завершение `main` завершает программу, поэтому просто запустить несколько горутин недостаточно — выполнение нужно синхронизировать.

## Каналы

```go
ch := make(chan int)
```

Небуферизированный канал синхронизирует отправителя и получателя:

```go
ch <- 42
value := <-ch
```

Буфер задаётся вторым аргументом:

```go
ch := make(chan int, 10)
```

Канал можно закрыть:

```go
close(ch)
```

При чтении можно проверить его состояние:

```go
v, ok := <-ch
```

## `select`

`select` позволяет ожидать несколько операций с каналами:

```go
select {
case v := <-ch1:
    fmt.Println(v)
case v := <-ch2:
    fmt.Println(v)
}
```

Если готовых операций нет, `select` блокируется.

`default` позволяет выполнить ветку, когда ни один `case` не готов:

```go
select {
case v := <-ch:
    fmt.Println(v)
default:
    fmt.Println("канал пока не готов")
}
```

## `nil` channel

Операции чтения и записи с `nil`-каналом блокируются. В конспекте это используется как способ временно исключить `case` из `select`.

## Deadlock

Deadlock — ситуация, когда горутины ждут события, которое не произойдёт.

```go
ch := make(chan int)
ch <- 42 // получателя нет
```
