## Package

Пакет — набор файлов одного каталога с одинаковым объявлением `package`. Они объединены общим пространством имён и компилируются вместе.

```go
package config
```

Экспортируемые идентификаторы начинаются с заглавной буквы, неэкспортируемые — со строчной.

## Module

Модуль — коллекция пакетов, которая версионируется как единое целое. Его граница определяется `go.mod`.

Создание:

```bash
go mod init github.com/username/project-name
```

## `go.mod`

Содержит описание модуля и его зависимостей.

Пример секций из конспекта:

```go
module github.com/username/project-name

go 1.21

require (
    example.com/package v1.2.3
)
```

Также могут использоваться `replace` и `exclude`.

## `go.sum`

Содержит криптографические хеши зависимостей и участвует в воспроизводимости сборок.

## Структура проекта

В конспекте отдельно выделяются:

```text
cmd/       точки входа
internal/  внутренние пакеты
pkg/       пакеты, которые предполагается использовать извне
```

Пакеты внутри `internal` ограничены правилами импорта Go.
